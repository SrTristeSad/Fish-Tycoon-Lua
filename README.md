# Fish Tycoon Lua

Reconstrução experimental em Lua + LÖVE 2D do jogo de aquários, baseada em engenharia reversa do J2ME. O código da versão 14, os testes e os recursos locais serão organizados neste repositório.

**Atenção:** recursos extraídos de um jogo comercial permanecem sujeitos aos direitos de seus titulares. Não são licenciados por este repositório.
